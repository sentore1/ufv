# PDF Export with Signature Space - Quick Guide

## How to Export Registration as PDF with Signature Space

### Step-by-Step Instructions

#### 1. Access the Registration
- Log in to Admin Dashboard at `/admin`
- Navigate to "Workshop Registrations"
- Find the registration you want to export
- Click on it to view full details

#### 2. Export to PDF
- Scroll to the bottom of the registration details
- Click the blue **"Export PDF"** button
- A new browser window will open with the registration form

#### 3. Print to PDF
The new window shows a formatted registration form with:
- All registration details organized by section
- Professional header with organization logos
- **Blank signature section at the bottom**

##### Option A: Using the Print Button
- Click the green **"Print to PDF"** button at the top or bottom
- Your browser's print dialog will open

##### Option B: Using Browser Menu
- Press `Ctrl+P` (Windows) or `Cmd+P` (Mac)
- Or use File → Print from browser menu

#### 4. Save the PDF
In the print dialog:
1. Choose **"Save as PDF"** or **"Microsoft Print to PDF"** as the printer
2. Click "Save" or "Print"
3. Choose where to save the file
4. Name it (e.g., `Workshop_Registration_John_Doe.pdf`)
5. Click Save

## What's Included in the PDF

### Header Section
✅ Three organization logos (UFV, IsDB, SIF)  
✅ Workshop title  
✅ Registration date

- **Section A:** Personal Information (name, gender, DOB, nationality, etc.)

- **Section C:** Contact Information (email, phone, emergency contact)
- **Section D:** Travel Information (country of departure)
- **Section E:** Language & Participation (languages, interpretation needs)
- **Section F:** Dietary Requirements
- **Section G:** Capacity Building Areas

### Signature Section
The PDF includes a **professional signature section** with:
- ✅ Declaration statement
- ✅ Large blank space for handwritten signature
- ✅ Date line: `Date: _____________________`
- ✅ Signature line: `Signature: _____________________`
- ✅ Clear border around the signature area

## Using the Signature Space

### For Physical Signing
1. **Print the PDF** on paper
2. The recipient can **sign by hand** in the blank space
3. Fill in the **date**
4. The signature makes it official documentation

### For Electronic Records
1. Save the unsigned PDF
2. Print it when needed for signing
3. Scan the signed document
4. File both digital and physical copies

## Troubleshooting

### Problem: PDF window doesn't open
**Solution:** Check if your browser is blocking pop-ups
- Look for a blocked pop-up icon in the address bar
- Click it and allow pop-ups from your site
- Try the Export PDF button again

### Problem: Print button doesn't work
**Solution:** Use keyboard shortcut
- Press `Ctrl+P` (Windows) or `Cmd+P` (Mac)
- This opens the print dialog directly

### Problem: Signature section is cut off
**Solution:** Adjust print settings
- In print dialog, select "Fit to page"
- Or set scale to 100%
- Check print preview before saving

### Problem: Logos don't appear
**Solution:** Enable background graphics
- In print settings, check **"Background graphics"** or **"Print backgrounds"**
- In Chrome/Edge: More settings → check "Background graphics"
- In Firefox: Print → check "Print backgrounds"
- This ensures logos and colors print correctly

### Problem: Can't find saved PDF
**Solution:** Check browser downloads
- Look in your Downloads folder
- Or check browser's download history (Ctrl+J)
- Default name includes registration name
